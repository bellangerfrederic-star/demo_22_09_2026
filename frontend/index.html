Trois agents, une chaîne de contrôle

Décomposition fonctionnelle issue du PRD.

Agent 1
Data Validator

Applique le catalogue de règles déclaré en JSON : valeurs nulles, unicité des clés, formats, plages autorisées et référentiels de valeurs.

Agent 2
Data Analyst

Détecte les anomalies statistiques (valeurs aberrantes par écart interquartile), explique chaque écart et mesure le déséquilibre des attributs sensibles.

Agent 3
Report Generator

Calcule le score pondéré par dimension, hiérarchise les anomalies et génère des tickets prêts à l’emploi (priorité, action, critère d’acceptation).
